Digital therapeutics just became a $9.4 billion market — and it needs an entirely new type of documentation that didn't exist 5 years ago.

We're witnessing the birth of a new medicine category: prescription software.

The landscape:
→ DTx market: $9.4B in 2025, projected $29B by 2030
→ FDA-authorized DTx products: 30+ (and growing)
→ Key players: Akili Interactive, Better Therapeutics, Freespira, Click Therapeutics
→ Conditions treated: substance abuse, insomnia, ADHD, chronic pain, diabetes management

Why documentation for DTx is completely different:

1. SOFTWARE IS THE DRUG
→ No molecule. No formulation. The "active ingredient" is an algorithm.
→ Traditional CMC documentation doesn't apply. Instead: Software Development Life Cycle (SDLC) documentation.

2. CONTINUOUS UPDATES
→ Unlike a pill, software gets updated. Each update potentially requires regulatory notification.
→ Writers must document version control, change impact assessments, and cybersecurity protocols.

3. CLINICAL EVIDENCE IS DIFFERENT
→ Endpoints include app engagement, behavioral change metrics, patient-reported outcomes.
→ Control arms are challenging — what's the "placebo" for an app?

4. REGULATORY PATHWAYS ARE EVOLVING
→ FDA's De Novo pathway for novel digital devices
→ Germany's DiGA (Digital Health Applications) framework — reimbursement pathway
→ No single global framework exists yet

5. PATIENT PRIVACY + EFFICACY DOCUMENTATION
→ HIPAA, GDPR compliance documentation alongside clinical efficacy data
→ Data architecture documentation becomes part of the regulatory package

Medical writers who understand BOTH clinical evidence AND software documentation will be in extraordinary demand.

This is a blue ocean. Who's swimming in it already?
